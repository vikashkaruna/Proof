## Real local component probe

The probe is `pnpm bench`, guarded by `AXIOM_W9_DISPOSABLE=1` and a local connection URL whose database name is exactly `axiom_w9_probe`. It creates a fresh 1,000,000-row PostgreSQL fixture, counts the inserted rows, uses a SELECT-only non-privileged role, exercises the actual `DiscoveryService` and `PostgresReadConnector`, then invokes the actual Chromium PDF renderer with fallback forbidden. Grant resolution and discovery-run recording are in-memory test doubles; the report is a synthetic renderer fixture without assessment source, founder review, or retained object. The probe never emits raw sampled data or database credentials. It drops only its dedicated schema and role on exit. CI runs the same probe against a disposable PostgreSQL service and uploads the JSON output.

Three local executions on the W9 worktree, PostgreSQL 16 Alpine and installed Google Chrome (observed range, not a statistical percentile):

| ----------------------------- | -------------------: |
| Verified fixture rows         |            1,000,000 |
| Fixture load                  | 1,213.54–5,183.81 ms |

| Distinct fixture rows sampled |                  200 |
| Chromium renderer             |     541.31–725.43 ms |
| PDF size                      |        111,844 bytes |

These are component timings on a local machine, not service SLO results. NFR-7 requires processing at least 1,000,000 records/hour through a sanctioned connector pipeline. The current SQL discovery API profiles at most 200 rows per request; its raw `read()` path refuses access until a redaction pipeline exists. Catalog enumeration returns relations, not records. Thus the probe can verify a 1M-row source and real discovery behavior but cannot measure the required million-record path. NFR-7 remains **UNVERIFIED**. A secure, paginated/redacted record path, then a sustained real connector load test with count, error, and duration evidence, is required.

NFR-8 requires standard report generation in under five minutes. The measured renderer is only one stage; source snapshot, founder review, BFF reconciliation, provider upload, immutable retention/version verification, and release are outside this probe. NFR-8 remains **UNVERIFIED**. Measure the complete source-bound workflow on preprod with real provider/storage, repeat over representative report sizes, and record p50/p95, errors, and artifact integrity.

No scheduled backup or full database and evidence-object restoration was exercised. NFR-9 RPO≤1h/RTO≤4h remains **UNVERIFIED** until a scheduled backup is restored into isolation, evidence bytes and retention metadata are checked, and observed recovery-point and recovery-time are recorded.
