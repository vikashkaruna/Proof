# W10 sovereign offline topology audit — 2026-09-30

**Status: OPEN.** This changes the on-prem path from a development Compose overlay into a standalone local topology and adds a fail-closed operator bootstrap. It does not establish production acceptance. The WORM server/client images referenced by the earlier overlay could not be pulled from Docker Hub (`repository does not exist`) or Quay (`401`) on this host, so no current Object Lock retention or immutable-delete test exists for this release. The new operator environment requires `AXIOM_WORM_SERVER_IMAGE` and `AXIOM_WORM_CLIENT_IMAGE` as preloaded immutable digests; both are deliberately blank in the example. A signed license, reviewed application images, and these WORM-capable archives are operator inputs, not generated by this worktree.

## Implemented contract

- `docker-compose.onprem.yml` is standalone. It starts local PostgreSQL with pgvector, GoTrue, PostgREST (dedicated `authenticator` login), an Nginx Auth/REST origin, Temporal with its own PostgreSQL, Redis, MinIO, model gateway, runtime, BFF, worker, and web. Redis, Temporal, model gateway, runtime, database, and MinIO have no published ports. The service network is `internal: true` and has no default route. No service refers to `host.docker.internal`, a hosted model provider, or a development password.
- `bootstrap-onprem.sh` requires a mode-0600 operator env, validates distinct secrets and JWT signatures/roles, verifies a signed offline license, requires every image preloaded, creates a clean application database, lets GoTrue own Auth migrations, applies the checksummed Axiom series, seeds the control library from inside the sovereign network, provisions and reads back seven-year Compliance Object Lock, then requests app startup. Any stage failure stops before the app starts. No demo users are seeded.
- The model gateway accepts `onprem` as a hardened mode, rejects hosted provider keys and nonlocal model URLs, requires a gateway key for both completion endpoints, forces all model requests to the local route regardless of an explicit hosted model name, and returns `503 local_model_unavailable` when no local model is configured/reachable. No synthetic success or hosted fallback occurs in this mode. A local model service/image is not bundled; its absence is explicit.
- The agent runtime applies production credential checks in `onprem` mode.
- The BFF checks the signed license on every on-prem request, including internal workload calls, so expiry after bootstrap blocks work; health and license diagnostics remain reachable and readiness returns 503. Every Compose image now requires an immutable digest and must already be loaded locally.

1. PostgreSQL started; `bootstrap-selfhosted.sql` created roles and an empty Auth schema; GoTrue applied its own migrations and started; Axiom migrations `0000`–`0087` completed on top. Reapplying the series reported already-applied checksums.
2. Auth public signup was rejected. Admin creation and password sign-in issued a token. PostgREST accepted that token (`200`) but tenant RLS returned zero rows; the service role saw the one fixture tenant (`200`, one row).
3. A container on the sovereign network failed to fetch `https://example.com` within three seconds. This proves the tested network's egress denial, not an enterprise firewall policy.
4. `pg_dump -Fc` from the application database restored into a clean `axiom_restore` database; the fixture tenant and all 88 migration records were present. This is a database restore check, not full system/MinIO recovery.
5. Local suites at the initial topology checkpoint: bootstrap/preflight unit tests 7/7, complete model gateway suite 29/29, agent runtime on-prem settings tests 3/3, targeted Ruff and Bandit checks, shell syntax, and Compose syntax validation passed. ## 2026-10-01 continuation

The isolated W10 worktree now requires a reviewed immutable digest for **every** Compose image, with preflight rejecting a mutable BFF tag. The BFF rechecks the signed offline license at request time; missing or expired licenses block application and private workload calls, while health remains available and readiness reports 503. The operator deployment guide now distinguishes authority-side license issuance from appliance installation and requires an authenticated license-status request.

Local verification after these changes: offline pnpm dependency installation reused 609 cached packages with zero downloads; BFF suite 90 passed files, 1,463 passing tests and ten existing skips; BFF typecheck and lint passed; focused request-time license tests 2/2; model gateway Python 3.11 suite 29/29; agent runtime on-prem settings 3/3; bootstrap/preflight Python 8/8; shell syntax and diff whitespace checks passed. No Docker service was started or mutated during this continuation because the combined W8 disposable database gate held the shared host; the prior isolated W10 rehearsal above remains the only live topology evidence.

**Still open:** Full signed-license install, maintenance-mode upgrade, complete PostgreSQL/Temporal/Object Lock/key restore, ingress/persona browser journeys, actual local model inference, and a tested seven-year WORM early-delete refusal require reviewed digests and operator artifacts. Request-time BFF license gating is not yet an independently verified license guard inside an already-running Temporal worker or runtime; that fail-closed path must be designed and tested before W10 release. No egress-blocked full-stack acceptance or production deployment is claimed.

## Outstanding production gates

- **WORM artifact:** Supply approved, license-compatible, vulnerability-reviewed, multiarch **server and client** image archives and immutable digests for `AXIOM_WORM_SERVER_IMAGE` and `AXIOM_WORM_CLIENT_IMAGE`. The server must accept the Compose `server /data --console-address` command; the client must support the `mc` alias, `mb --with-lock`, and `retention set/info --default` commands. They must implement S3 Object Lock at bucket creation, seven-year default `COMPLIANCE` retention, retention readback, versioned object readback, and refusal of early deletion. The bootstrap fails before any stack change when these variables/images are absent.
- **Application images:** Build/review/pin BFF, web, runtime, worker, and model gateway images from this revision, preload them locally, then run a signed-license bootstrap. No current full stack install, persona/browser run, local model inference, upgrade, or full database-plus-object restore has passed. The BFF image must contain the control-library seed script and its dependencies for the in-network seed invocation.
- **All image manifests:** Supply and preload reviewed digests for PostgreSQL, GoTrue, PostgREST, ingress, Temporal, Redis, and every application image; mutable tags are refused by preflight. The current host has some legacy image tags, but they are not an approved release set for this revision.
- **Intranet access:** Docker Desktop's `internal: true` network suppressed host-published service ports during this rehearsal. An approved ingress plus host/network egress policy must be designed and tested before a browser can use the workbench while the data plane remains blocked from external egress. Do not relax the internal network merely to make browser access work.
- **Operational recovery:** Restore must cover Supabase Auth, Axiom database, Temporal state, MinIO object versions/retention, key material, and signed license together; validate real personas and auditor readback after restore. The database-only restore above is a partial result.
