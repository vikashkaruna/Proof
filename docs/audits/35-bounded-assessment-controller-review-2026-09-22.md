## Findings and implementation

1. **Worker lifetime was controller-dependent.** The previous private Docker channel had no independently enforced process-tree deadline. A Linux root supervisor now launches only the fixed assessment worker as UID/GID 20003, clears supplementary groups, allowlists its environment, applies resource limits/no-new-privileges and enforces a wall-clock bound. It uses subreaper adoption and pidfd signaling to terminate detached descendants and waits for complete reaping. Cleanup failure cannot be reported as success. Kernel parent-death signals and the post-binding parent check protect the fixed worker/identity-CLI chain if its parent is abruptly killed. This is a local process primitive; production per-job PID/tenant isolation is still required.
2. **Transport and persistence outcomes were conflated.** The bounded channel validates exact task/run/tenant context, input binding, tool ordering, frame/total sizes and worker/supervisor terminal consistency. Each actual tool still authenticates the fresh worker SVID. It requires the supervisor's final report and process EOF; duplicate or forged reports are rejected. Private stdio is never logged, and errors are sanitized. A worker success frame is not persistence evidence.
3. **The recovery pieces lacked one controller boundary.** A private metadata-only owned-job lookup now feeds a controller that claims once, launches through the trusted channel and independently confirms the immutable SQL result. Claimed jobs are never relaunched. Confirmation is attempted after channel loss, claim races or launch failures. Confirmation and cleanup have separate fields; recovery without launch reports unknown cleanup. No scheduler, browser endpoint or default service activation was added.
4. **Default launch could accidentally become a log channel.** The image entry point now refuses implicit activation; explicit supervisor activation also requires root and FIFO stdio. These are refusal guards, not proof that an external collector is absent. Deployment must wire private pipes and prohibit log capture. The fixed worker has neither backend credentials nor network access in acceptance. The trusted root monitor remains separate from that worker.
