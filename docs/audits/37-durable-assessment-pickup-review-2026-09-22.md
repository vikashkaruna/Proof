## Findings and implementation

- **The outbox commit and Temporal submission had no durable pickup path.** Migration 0045 extends the existing private outbox with due-time polling, `FOR UPDATE SKIP LOCKED` leases and namespace binding. An explicit private producer pump submits only tenant/job IDs using the existing stable workflow ID and duplicate-execution refusal. A lost submission response can recover the same execution after a new lease is acquired. A scheduling lease is not task authority.
- **A stale producer could otherwise acknowledge somebody else's retry.** The SQL acknowledgement checks the tenant/job, current lease UUID and deadline, pinned namespace, canonical workflow ID and observed execution UUID. A repeated matching submitted acknowledgement returns the same append-only receipt. Changed execution metadata conflicts. Mandatory audit failure rolls back the acknowledgement. The scheduler has no database credentials; the trusted BFF adapter is the only persistence caller.
- **Expired or previously claimed tasks must not create replacement work.** Reservation permits first submission only for an unclaimed, queued assignment passing current task checks. Otherwise the producer may only describe an existing workflow. Controller claim and each scoped tool still repeat authority checks. Task expiry, claim state and terminal results are never reset. Missing history remains unconfirmed, including after Temporal retention expires.
- **Indefinite uncertain pickup needed a stopping condition.** A live lease is exclusive. After bounded attempts, the next due poll records an audited review handoff and stops scheduling that row. Review closure acquires at most one tenant's ledger counter per poll transaction to avoid opposite cross-tenant counter lock order. Review does not claim that an assessment failed or rolled back.
- **Private mode needed explicit lifecycle wiring.** `--assessment-outbox-pump` requires the existing socket/owner options. Only the opaque assessment queue is polled; the legacy worker remains separate. The pump and worker tasks cancel together. Private transport exposes fixed poll/ack operations with strict schemas and bounded request/response sizes. Caller input cannot select a namespace or tenant shard at polling time. Both new ledger actions are included in the shared TypeScript enum.
