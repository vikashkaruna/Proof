# Revision 115 — reviewed board artifact versions (2026-09-30)

## Scope

Migration 0087 adds one fixed board artifact build per report and one immutable source JSON and PDF version each. The begin RPC requires the frozen request source, current approved report and immutable founder review, fixes both deterministic object keys and a seven-year retention deadline, and appends a ledger event. Settlement accepts only exact descriptor and version receipts. Board release now requires both versions and the expected PDF SHA-256; legacy generated/statutory reports remain blocked. The service role can read the tables but cannot write their rows directly.

The BFF renders the final PDF from the exact frozen source and reviewed document. It uses the recorded founder review as the visible signature. Chromium is required; silent text-only fallback is refused for retained artifacts. Only fixed-width Chromium date metadata is normalized to the immutable review time so an explicit retry can reproduce the same PDF bytes without inventing a document date. The BFF records no settlement until the provider confirms the exact version's bytes, metadata, encryption and Compliance retention. Initial and retry uploads use conditional PUT. Reconciliation never uploads. A founder may explicitly retry a missing object only after an exact-key provider lookup confirms absence; ambiguity remains pending. Published PDF reads retrieve the retained version and recheck current membership before returning bytes.

Production chart review found the BFF's read-only root lacked writable temporary space for Chromium. The BFF deployment now mounts a bounded 256 MiB `/tmp` volume; the renderer uses it for a private HTML file and isolated browser profile, cleans both, and disables JavaScript and background networking in the child process. The rendered-manifest gate now refuses a read-only BFF root without that mount.
