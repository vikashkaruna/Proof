# Documentation conventions

- Zones, module codes and the file-naming convention are defined in
  [`../README.md`](../README.md).
- One file per module per document type; content grows inside the file.
- Operator procedures always state **What (purpose)**, **Why (reason)**,
  **How (steps)**, **Expected output** and **Confirm (validation)**.
- The session log is a single file, newest entry first.
- Never put secrets, real hostnames, tenant names, account identifiers or
  topology in a shared document.
