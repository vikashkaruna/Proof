# SEC-3 · service-role usage baseline in apps/web
#
# `createSupabaseAdmin()` uses the Supabase service-role key, which bypasses RLS
# by design. `packages/supabase/src/admin.ts` states the invariant: "The Next.js
# apps NEVER use this." These files break it, and because most of them also
# carry no tenant filter, any authenticated user of any tenant can currently see
# every tenant's findings, evidence, DSARs, breaches, reports and approvals.
# NFR-2 ("tenant isolation — absolute") is false in the running product even
# though the database policies are correct.
#
# This file is a RATCHET, not an allowlist. The W0.0 gate fails on any file not
# listed here, so the set cannot grow. W1 migrates each page to the user-scoped
# client and deletes its line. The gate passes trivially once the list is empty.
#
# Do not add to this file.
