# Axiom Proof

Application source, executable tests and maintenance tools are versioned here.

Documentation map and confidentiality policy: [docs/README.md](docs/README.md).
Shareable guides live in [docs/shared-docs](docs/shared-docs/README.md). Operator
guides, architecture, requirements, testing, status, audits and plans are

worktrees. Never commit or publish their contents. Agent instructions remain in
[AGENTS.md](AGENTS.md).
